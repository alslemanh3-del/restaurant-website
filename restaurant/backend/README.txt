مجلد الباك إند (Backend)
========================
في هذه المرحلة تمّ إنشاء الواجهة الأمامية (Frontend) فقط.

سيُضاف الباك إند لاحقًا، ويمكن ربطه كالتالي:
- نموذج الحجز في frontend/script.js جاهز لإرسال البيانات إلى API
  (انظر الدالة submitReservation داخل الملف — استبدل المحاكاة بـ fetch).

بنية مقترحة لاحقًا:
  backend/
    ├── server.js        (خادم Express مثلاً)
    ├── routes/
    ├── models/
    └── package.json
