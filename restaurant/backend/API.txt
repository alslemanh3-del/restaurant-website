================================================================
 مطعم الذوق — مرجع نقاط API
 Base URL: http://localhost:5000/api
 (في بيئة المعاينة: عبر البوابة http://localhost:81/api?XTransformPort=5000)
================================================================

كل الاستجابات JSON. الترميز UTF-8 (يدعم العربية).
CORS مفعّل لكل المصادر (*) — مناسب للربط المتبادل.

----------------------------------------------------------------
1) GET /api/health
----------------------------------------------------------------
فحص صحة الخادم.

مثال:
    GET /api/health

استجابة 200:
    {
      "status": "ok",
      "service": "مطعم الذوق API"
    }

----------------------------------------------------------------
2) GET /api/info
----------------------------------------------------------------
معلومات المطعم.

استجابة 200:
    {
      "name": "مطعم الذوق",
      "city": "اللاذقية",
      "phone": "+963 41 552 3344",
      "email": "info@al-thawq.com"
    }

----------------------------------------------------------------
3) GET /api/categories
----------------------------------------------------------------
قائمة تصنيفات قائمة الطعام.

استجابة 200:
    [
      {"key": "appetizers", "label": "المقبلات"},
      {"key": "mains",      "label": "الأطباق الرئيسية"},
      {"key": "grills",     "label": "المشاوي"},
      {"key": "salads",      "label": "السلطات"},
      {"key": "desserts",   "label": "الحلويات"},
      {"key": "drinks",      "label": "المشروبات"}
    ]

----------------------------------------------------------------
4) GET /api/menu
----------------------------------------------------------------
قائمة كل الأطباق المتوفرة.

معاملات استعلام اختيارية:
    category=<key>   تصفية حسب التصنيف (مثال: ?category=grills)

مثال:
    GET /api/menu?category=grills

استجابة 200:
    [
      {
        "id": 7,
        "name": "شيش طاووق",
        "category_key": "grills",
        "description": "أصابع الدجاج المتبّلة...",
        "price": 55.0,
        "rating": 4.9,
        "image": "img/shish-tawook.png"
      },
      ...
    ]

----------------------------------------------------------------
5) POST /api/reservations
----------------------------------------------------------------
إنشاء حجز جديد.

الطلب (Body — JSON):
    {
      "name":  "أحمد العلي",      // مطلوب، حرفان على الأقل
      "phone": "0944221889",      // مطلوب، 8-13 رقمًا
      "people": "4",             // مطلوب
      "date":  "2026-10-02",     // مطلوب، YYYY-MM-DD
      "time":  "19:30",          // مطلوب، HH:MM
      "notes": "نافذة"            // اختياري
    }

مثال (curl):
    curl -X POST http://localhost:5000/api/reservations \
      -H "Content-Type: application/json" \
      -d '{"name":"أحمد","phone":"0944221889","people":"2","date":"2026-10-02","time":"19:30","notes":""}'

استجابة 201 (نجاح):
    {
      "ok": true,
      "ref": "R-000001",
      "id": 1
    }

استجابة 400 (خطأ تحقق):
    {
      "ok": false,
      "errors": {
        "name": "الاسم مطلوب (حرفان على الأقل)",
        "phone": "رقم هاتف غير صحيح (8-13 رقمًا)"
      }
    }

----------------------------------------------------------------
6) GET /api/reservations
----------------------------------------------------------------
قائمة كل الحجوزات (مرتبة تنازليًا حسب تاريخ الإنشاء).

استجابة 200:

      ...
    ]

----------------------------------------------------------------
7) GET /api/reservations/<id>
----------------------------------------------------------------
حجز واحد حسب المعرّف.

مثال:
    GET /api/reservations/1

استجابة 200: كائن الحجز (كما في GET أعلاه).
استجابة 404:  {"ok": false, "error": "الحجز غير موجود"}

----------------------------------------------------------------
8) POST /api/reservations/<id>/status
----------------------------------------------------------------
تحديث حالة حجز (للوحة الإدارة).

الطلب (Body — JSON):
    {"status": "confirmed"}    // pending | confirmed | cancelled

استجابة 200:
    {"ok": true, "id": 1, "status": "confirmed"}

استجابة 400: حالة غير صالحة.
استجابة 404: الحجز غير موجود.

----------------------------------------------------------------
9) POST /api/contact
----------------------------------------------------------------
إرسال رسالة تواصل.

الطلب (Body — JSON):
    {
      "name":    "سامي",          // مطلوب، حرفان على الأقل
      "email":   "sami@x.com",   // اختياري
      "message": "مرحبًا..."      // مطلوب
    }

استجابة 201:
    {"ok": true, "id": 3}

استجابة 400:
    {"ok": false, "errors": {"name": "الاسم مطلوب", "message": "الرسالة مطلوبة"}}

================================================================
جدول الحالات (status) للحجوزات
================================================================

pending    ← افتراضي: الحجز قيد المراجعة
confirmed  ← أكّده المطعم
cancelled  ← أُلغي

================================================================
أخطاء شائعة
================================================================

• 404 من Flask      → مسار غير موجود. تحقق من URL.
• 400               → خطأ في بيانات الطلب. راجع errors.
• فشل اتصال (fetch)  → تأكد أن Flask يعمل على المنفذ 5000.
• صفحة HTML بدل JSON → ربما أصبت Next.js (المنفذ 3000) بدل
                       البوابة (81) أو Flask (5000).
